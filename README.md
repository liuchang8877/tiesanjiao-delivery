# 铁三角交付手册

《华为铁三角工作法》（范厚华，中信出版集团）的读书笔记互动版，从软件项目交付的角度用大白话整理。

在线访问：

- 国内：https://achang-d0gimipc60590a0f5-1256158283.tcloudbaseapp.com/tiesanjiao/
- GitHub Pages：https://liuchang8877.github.io/tiesanjiao-delivery/

## 内容

| 板块 | 说明 |
|---|---|
| 三个角色 | 可点击的铁三角图：客户经理、方案经理、交付经理的职责模型、考核和软件项目对应 |
| LTC 流程 | 从线索到回款的三段流程和五个决策关口 |
| 案例库 | 13 个与交付相关的案例，可按主题筛选 |
| 现场交付 | 技术项目经理从进场到收尾的 8 步清单（可打勾，进度存在本地浏览器） |
| 示例 | 虚构的跨团队项目，处理前后对照 |
| 讨论 | 7 个可以拿去开会讨论的问题 |

## 说明

本页是个人读书笔记，内容为概括和改写，不含原书文字和插图；"示例"部分为虚构场景。

单个 `index.html` 文件，无需构建，直接用浏览器打开即可。
